**Transforming HR Data into Actionable Workforce Insights**

An interactive HR Analytics Dashboard built using **Microsoft Power BI** to analyze employee data, monitor workforce trends, and support data-driven HR decision-making.

## 🚀 Project Overview

This project focuses on analyzing HR data to understand workforce composition, employee demographics, and key HR metrics through interactive visualizations.

The dashboard helps HR teams explore employee information, identify patterns, and make informed decisions using data analytics.

## 🎯 Project Objectives

- Analyze employee data and workforce distribution.
- Monitor key HR performance indicators.
- Explore employee demographics and organizational trends.
- Present insights through interactive Power BI visualizations.
- Support data-driven human resource management.

## 🛠️ Tools & Technologies

- **Power BI Desktop** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and calculated metrics
- **Data Visualization** — Charts, KPI cards, and interactive filters

## 📈 Dashboard Features

- Interactive HR analytics dashboard
- KPI cards for important workforce metrics
- Employee data analysis and visual comparisons
- Interactive slicers and filters
- Visual representation of HR trends
- Easy-to-understand reporting for business users

## 🔍 Key Business Questions

1. What is the overall workforce composition?
2. How are employees distributed across different categories?
3. What patterns can be identified in employee demographics?
4. Which HR metrics should management monitor?
5. How can interactive reporting improve HR decision-making?

## 🧹 Data Preparation

The project uses Power BI data preparation features to organize data for analysis.

- Checked data types and column formats.
- Prepared data for visualization.
- Created appropriate measures where required.
- Organized metrics and visuals for easier interpretation.

## 💡 Business Value

This dashboard demonstrates how business intelligence tools can convert HR data into meaningful insights. It helps users explore workforce information efficiently and supports better reporting and decision-making.

## 🖥️ How to Run the Project

1. Download or clone this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` file in Power BI Desktop.
4. Refresh the data if the original data source is available.
5. Explore the dashboard using its filters and visualizations.
